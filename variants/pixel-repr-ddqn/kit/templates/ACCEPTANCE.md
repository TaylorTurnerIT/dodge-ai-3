# Phase acceptance template

Template only; not evidence. Copy after execution into kit/acceptance with phase and revision in filename. Raw artifacts stay under the new variant history root.

- Phase / mode / canonical task IDs:
- Source commit / dirty diff hash / SPEC and protocol hashes:
- Requested scope / predecessor acceptance links:
- Code status: unopened / active / implementation-complete / not-applicable
- Evidence status: missing / invalid / ready
- Scientific result: not-applicable / positive / negative / inconclusive
- Gate decision: pending / accepted / rejected
