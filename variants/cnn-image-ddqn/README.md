# CNN image Double-DQN

This is the first isolated major-model variant. It trains from a simplified
collision-system image rather than the native rendered framebuffer. The image
contains only collision-relevant geometry, so particles, palette effects, UI,
and other visual decoration cannot become shortcuts for the learner.

The initial observation is four grayscale 84×84 frames stacked as
`(4, 84, 84)`. The temporal stack is a deliberate experiment parameter: later
runs can compare one, two, four, and eight frames without changing the Rust
game or action contract.

The model is the standard Atari-style convolutional trunk:

```text
(N, 4, 84, 84)
  Conv(4→32, 8×8, stride 4) + ReLU
  Conv(32→64, 4×4, stride 2) + ReLU
  Conv(64→64, 3×3, stride 1) + ReLU
  Flatten(3136)
  Linear(3136→512) + ReLU
  Linear(512→9)
```

The shared 512-unit representation feeds a dueling value stream and advantage
stream, combined as `Q=V+(A-mean(A))`. The output is raw Q-values. The agent
uses Double-DQN action selection with an online network, target network,
`uint8` replay storage, epsilon-greedy exploration, Huber loss, and gradient
norm clipping at 10.0.

There is intentionally no batch normalization, max-pooling, RGB input, or
spatial augmentation in this first variant.

## Run it

```bash
scripts/uv-run dodge-cnn-image-run \
  --history-root history/dodge/gymnasium \
  --run-id cnn-image-ddqn-baseline-001 \
  --steps 256 --stack-size 4 --device auto
```

The LaunchSpark-parity dashboard is a Pygame window with the upstream layout:
Reward, Progress, Achievements, Policy Entropy, Survival Time, Enemies Killed,
Learning Statistics, System, Pause/Resume, Reward Weights, Game Configuration,
Watch Agent, and Model Checkpoints.

```bash
scripts/uv-run dodge-cnn-image-dashboard \
  --history-root history/dodge/gymnasium \
  --run-id cnn-image-ddqn-dashboard-001 \
  --steps 250000 --stack-size 4 --device auto
```

It runs the native Rust collision-image DDQN session in a background thread,
polls the same bounded run artifacts, and queues dashboard controls at learner
safe points. Named checkpoints use `.pt` files. `Watch Agent` starts a separate
read-only browser replay page on the host's Tailscale address (`:8890`), using
84×84 collision-system images generated by a fresh native Rust lane rather than
rendered game pixels or the live training lane.

The browser page provides play/pause, restart, single-step controls, a timeline,
and native-frame/action/reward diagnostics. `just dashboard-url` prints the
expected URL shape; the concrete replay URL appears as a dashboard toast when
the checkpoint replay is ready. `just replay-server` is available when a
standalone empty replay service is useful for connectivity checks.

For a deterministic visual smoke check:

```bash
just dashboard-screenshot artifacts/launchspark-dashboard.png
```

Use `--stack-size 1`, `2`, `4`, or `8` for later temporal comparisons. Those
comparisons remain separate from the initial baseline.

Implementation and acceptance criteria live in [SPEC.md](SPEC.md). This
directory intentionally does not contain scalar/MLP input work; that belongs to
later variants.
