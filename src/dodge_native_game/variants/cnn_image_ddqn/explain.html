          How to read this page
          

            
Trace order. Each frame is a pre-action snapshot: the input stack and Q/V predictions are evaluated before the listed action. Reward and done are the native result after that action. The page never reconstructs game state.

            
Q, V, and head type. Q values are raw action values, not probabilities. V is shown only when the API returns a scalar value; a null V is expected for a plain Q head. Centered advantages are shown when present.

            
Signed maps. The map is original minus perturbed for one fixed chosen/alternative action pair. Red means perturbing that location lowered V or weakened the fixed action preference; blue means it raised V or strengthened that preference. The zero-centred scale stays fixed while switching value and decision views for that response.

            
Feature evidence. Conv3 maps are 64 channels at 7×7. Ablation Q values show the result after zeroing the selected channel. The ranking includes all 512 contribution entries, ordered by absolute magnitude. Examples are convenience links, not extra evidence.

            
Limits. Sensitivity and ablation can show where this network changes its output; they are not attention, confidence, causality, or a guarantee that the policy will behave the same on another input.
